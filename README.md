# Business Bankruptcy Prediction — Poland

Analysis and modeling of financial datasets from over 10,000 Polish companies 
(2000–2013) to predict business bankruptcy.

## Technologies
Python · scikit-learn · pandas · matplotlib · seaborn

## Models compared
- Random Forest
- Logistic Regression

## Main result
Random Forest showed greater specificity, being more reliable in avoiding 
false positives in bankruptcy prediction.
